## Exact entry text

**G-159. Three tests depend on the Node build's certificate store.** `packages/api/tests/unit/distrustCompromisedRoots.test.ts` passes on the official Node 24.22.1 release and fails on a Node build whose bundled roots differ. Status: open. CI now pins Node 24.22.2 (PR #485), and the production images run the official Node 24.22.2 binary, so the tests run on the build production ships. A startup check (`assertListedRootIsBundled`, called before the removal in `packages/api/src/server.ts`) now refuses to start when the bundled store holds none of the listed roots. Closing it needs the Node version and build pinned in CI, so every run uses the same certificate store, and the security follow-up tracked outside this repository completed. Process: linked to that follow-up; no public issue, by design.
