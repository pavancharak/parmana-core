## Exact entry text

**G-120. A schema version 2 record can be downgraded by anyone who can write to storage.** `schemaVersion` is covered by neither the legacy signature nor `trustRecordHash`. Removing `signatures` and setting `schemaVersion` to 2 leaves a record that still passes on the legacy signature. The cutover (`HYBRID_REQUIRED_FROM` on the server, `hybridRequiredFrom` in the offline trust file) closes this for records created at or after it. The server variable is unset, so the gap remains open for every existing record. Status: open, accepted for records created before a cutover, closed for records after one. Engineering: set `HYBRID_REQUIRED_FROM` only once every new record is hybrid-signed, which depends on G-119.
