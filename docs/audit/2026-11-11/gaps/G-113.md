**G-113. The execution-boundary signal check fails open during bootstrap.** `LateBoundSignalStateVerifier.findViolations` returns no violations until `bind()` is called. The hash check still runs; only the real-world divergence check is skipped in that window. `createApplication` binds it during startup. Fix: `LateBoundSignalStateVerifier.findViolations` throws until `bind()` runs, so an execution that reaches the check during bootstrap is refused, not released unchecked.
