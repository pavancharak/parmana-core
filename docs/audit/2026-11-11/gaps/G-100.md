## Exact entry text

**G-100. Connector credentials could be sent to an unchecked base URL, and a 2xx non-JSON merge or update counted as success.** `HUBSPOT_BASE_URL`, `GITHUB_BASE_URL` and `SLACK_BASE_URL` reached the production connectors with no scheme or host check, so `http://` sent the token in clear text. The GitHub and HubSpot adapters also parsed a non-JSON 2xx body as `{}` and recorded success. Fix: `readConnectorBaseUrl()` enforces https (or loopback http) and refuses embedded credentials; the adapters fail when the body is not JSON. Tests: connector and gateway suites pass. Status: reported fixed on branch `fix/policy-scan-and-governance-url`, which is no longer in the repository, so whether this reached `main` is not verified. Residual: the connector check cannot tell whether a loopback address is a real mock or a local proxy.
