## Exact entry text

**G-105. Test and development environments skipped policy governance by default.** The approval-record check was relaxed whenever `NODE_ENV` was `test` or `development`. A deployment that set either one ran policies with no approval record. Fix: relaxation needs an explicit `PARMANA_ALLOW_UNGOVERNED_POLICY=true` in those two environments, and `POLICY_EXECUTION_VERIFICATION_ENFORCED=true` still forces enforcement (`packages/api/src/bootstrap/policyGovernanceRelaxed.ts`). The policy hash is always required. Status: fixed on branch `ccr-6f1b8d3b-o5pqwj` (commit ddb6009); that branch and commit are no longer in the repository, so whether this reached `main` is not verified. Residual: the test suite sets the opt-in in `vitest.setup.ts`, so tests still run relaxed. That is intentional, but it means the tests do not exercise the enforced path by default.
