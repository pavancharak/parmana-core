## Exact entry text

**G-153. No agent rollback, and no guard against automatic restart after an emergency stop.** The kill switch stops new execution, but Parmana cannot roll an agent or its policy back to a known-good state, and does not refuse a restart that an operator did not request. CERT-In AI Security Auditing Guidelines v1.0 section 9.7 requires rollback and prevention of uncontrolled automatic restart for high-risk agentic systems, and section 10.6 requires a tested rollback capability for Tier 3 and 4. Status: open. Opportunity: define rollback (previous approved policy version and previous agent key grants), test it, and record a refusal for any restart that is not an explicit operator action. Related to G-122. Process: linked issue #463.
