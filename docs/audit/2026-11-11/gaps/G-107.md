## Exact entry text

**G-107. The HubSpot verification fetch carried no policy hash.** The HubSpot signal-state verifier signs its own `hubspot:deal-fetch` authorization and sends it through the gateway. The gateway requires a policy content hash, so in production that fetch was refused and the deal-update signal check failed closed. Test mode had hidden this because it relaxed the requirement. Fix: the fetch authorization binds to the content hash of `hubspot-deal-update@1.0.0`, resolved through the same policy repository the gateway checks. Status: fixed on branch `ccr-6f1b8d3b-o5pqwj` (commit ddb6009); that branch and commit are no longer in the repository, so whether this reached `main` is not verified. Residual: the fetch still self-asserts its outcome (G-111).
