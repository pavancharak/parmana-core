## Exact entry text

**G-102. Smaller leaks and gaps found by the audit.** The public `/ready` route returned database error text. The Python connector SDK `CredentialHandle` printed its token in `repr`. The governance UI had no timeout on its API calls. The policy gate read `NODE_ENV` to decide whether to run, so a committed `.env` line could switch it off; the gate walked neither symlinked policy directories nor the directory `PARMANA_POLICY_DIR` named. `rotate-caller-key` wrote to a path built from an unchecked caller id, and `generate-fly-secrets` regenerated signing keys on every run. The `rate_limit_counters` table had no row level security, so the Data API's anon role could reach it. The Razorpay example reported a post-POST failure as a misconfiguration. Fix: each item corrected as described in CLAIMS 3.26. Status: reported fixed on branch `fix/policy-scan-and-governance-url`, which is no longer in the repository, so whether this reached `main` is not verified. Residual: the RLS migration has not been applied to the live Supabase project, so the live grants are still unverified.
