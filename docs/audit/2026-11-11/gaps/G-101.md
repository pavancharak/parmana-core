## Exact entry text

**G-101. The TypeScript SDK accepted any endpoint and printed its API key, and the SDKs trusted a non-boolean `valid` and an unencoded path id.** The Python SDK refused plain http to remote hosts; the TypeScript SDK did not. `console.log(client)` and `JSON.stringify(client)` exposed the key. Path ids were not encoded, so `../` could re-route a request. `valid` was returned as-is, so a string `"false"` read as true. Fix: `assertSafeEndpoint()`, an inspect/`toJSON` that omit the key, `encodeURIComponent` and `quote` on path ids, and a strict `=== true` check. Tests: `typescript/test/EndpointGuard.test.ts`; Python SDK suite passes. Status: reported fixed on branch `fix/policy-scan-and-governance-url`, which is no longer in the repository, so whether this reached `main` is not verified. Residual: eight TypeScript SDK test files do not load in this environment, with or without these changes.
