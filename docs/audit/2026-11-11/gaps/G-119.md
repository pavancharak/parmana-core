## Exact entry text

**G-119. Hybrid signing is not live on any deployment.** Production runs `CRYPTO_MODE=single`, so its records carry only the Ed25519 signature. The hybrid code path is covered by the runtime and crypto tests. A test project was once configured for hybrid and passed `/ready`, but no live hybrid record was created and verified through its API, and that project was removed on 2026-10-23. Turning hybrid on in production also needs the production key material extended with an ML-DSA-65 key. The current signing key exists only in Vercel and must be kept unchanged, or existing records stop verifying. Status: open, operator decision. Engineering: create and verify a live hybrid record on a separate test deployment first, then change production with a redeploy and check that new records carry `signatures`. Keep `HYBRID_SIGNATURE_REQUIRED` off until then.
