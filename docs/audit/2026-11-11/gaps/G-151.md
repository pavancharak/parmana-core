**G-151. No approved inventory of tool and MCP connections for agents.** Parmana keeps no approved inventory of the tool servers, plugins, MCP services or agent-to-agent connections an agent may use, and does not check tool descriptions when they change. CERT-In AI Security Auditing Guidelines v1.0, section 9.7 and Table 16 require an approved inventory of permitted connections, authenticated tool identities, validated tool descriptions and assessment of new connections before production use. Status: open. Opportunity: a registry of approved tool and MCP connections, bound to the agent's key and checked on each call, with a record when a connection is added. Process: linked issue #461.
