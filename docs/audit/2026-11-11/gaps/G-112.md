## Exact entry text

**G-112. The offline verifier loads the repository `.env`.** The verification package imports `@parmana/shared`, whose configuration module calls `dotenv.config()` when it loads, so a third party's verifier process reads a `.env` file in the working tree. It loads no key material and uses none of the values, but the verifier is not isolated from the filesystem. Fix: `dotenv` now runs once, from the first `loadConfig()` call, not when `@parmana/shared` is imported. Importing the verifier reads no file. Dotenv's banner is silenced so it does not write to the console. Status: fixed on branch `ccr-6f1b8d3b-o5pqwj`; that branch and commit are no longer in the repository, so whether this reached `main` is not verified. Residual: none for the verifier; server processes still read `.env` when they load configuration.
