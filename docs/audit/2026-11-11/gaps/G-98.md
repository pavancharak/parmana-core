## Exact entry text

**G-98. The Vercel serverless entry did not refuse startup on a Policy Governance integrity mismatch, and skipped the Paytm connector guard.** `api/index.ts` called `runPolicyGovernanceIntegrityCheckAtStartup()` without awaiting it and without refusing, so a live policy with no matching approval record could be served. The entry also never ran `assertPaytmConnectorConfigured()`, so `PAYTM_CONNECTOR_URL=http://...` could run with the shared secret in plaintext. Its import pointed at a `dist` module that has no source. Fix: the entry awaits `assertPolicyGovernanceIntegrityAtStartup()` inside `buildApp()`, so a mismatch fails every request, and runs the Paytm guard at module load. Status: reported fixed on branch `fix/policy-scan-and-governance-url`, which is no longer in the repository, so whether this reached `main` is not verified. Residual: no process exit in serverless, so refusal is per request, not per process. Tests: the entry is not covered by an automated test; the change was checked by typecheck and by the `packages/api` suite.
