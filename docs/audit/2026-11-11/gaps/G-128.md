## Exact entry text

**G-128. Connector credentials are readable by code on the same host.** In env mode, the connector credential providers read each credential from the server's environment (`packages/api/src/bootstrap/secrets/EnvSecretsProvider.ts` is an identity pass-through). Code in the same process, container or host that can read that environment can read the credential. The README claim that the agent never holds the real credentials holds for callers of the HTTP API. It does not hold against that code. Status: open. The README wording now names this limit. Remaining options are isolating the gateway's secrets (a separate process, or a secrets store the server process cannot read directly), which is a design decision, or accepting the same-host exposure as part of the threat model. Tracked as backlog row 52. Claim: README, "When it runs"; CLAIMS 2.16.
