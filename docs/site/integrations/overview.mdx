---
title: "Integrations"
description: "How Parmana connects to the systems it releases approved actions to. Parmana ships no built-in connectors; an operator registers an external connector."
---

Parmana does not ship built-in connectors. The connectors that were once built into this repository moved out of it under [ADR-0018](https://github.com/pavancharak/parmana-core/blob/main/docs/adr/ADR-0018-Connectors-Outside-Core.md).

To connect a system, an operator registers an **external connector**: a capability, the HTTPS endpoint that serves it, and the policy that governs it.

- One person proposes the registration, and a different person approves it through maker and checker, with no deploy ([ADR-0013](https://github.com/pavancharak/parmana-core/blob/main/docs/adr/ADR-0013-Generic-External-Connector.md)).
- Once active, Parmana sends each approved action to the endpoint as a signed release. The endpoint checks the release's signature and audience, and it needs no shared secret.

To write an endpoint, see the [Connector Development Guide](/integrations/connector-development-guide). To configure the endpoint a self-hosted deployment releases to, see [Connect a system](/self-hosted/connectors).
