> **ResolveExecutionIntentOutcome** = `"RESOLVED"` \| `"ALREADY_RESOLVED"`

RESOLVED: this call closed the intent. ALREADY_RESOLVED: it was already
closed, nothing was changed, and the original statement is returned.
