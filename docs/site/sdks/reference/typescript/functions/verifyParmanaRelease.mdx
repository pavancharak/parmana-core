> **verifyParmanaRelease**(`body`, `options`): `Promise`\<[`ParmanaReleaseVerification`](/sdks/reference/typescript/type-aliases/ParmanaReleaseVerification)\>

Checks, in order: the body's shape, the signature over the canonical
JSON of `release` with the key named in signature.keyId, that
release.audience equals `audience`, and that release.expiresAt has not
passed (with the clock skew allowance). Only then does it ask
isAlreadyExecuted. Never throws for a bad body; returns
`{ valid: false, errors }`.

## Parameters

### body

`unknown`

### options

[`VerifyParmanaReleaseOptions`](/sdks/reference/typescript/interfaces/VerifyParmanaReleaseOptions)

## Returns

`Promise`\<[`ParmanaReleaseVerification`](/sdks/reference/typescript/type-aliases/ParmanaReleaseVerification)\>
