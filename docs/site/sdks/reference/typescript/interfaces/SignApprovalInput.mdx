| Name | Kind | Type | Description |

| `keyId` | Property | `string` |  |
| `capability` | Property | `string` | The action approved, such as paytm:refund or github:pr-merge. |
| `resourceId` | Property | `string` | The value at the policy's approvalSignals resourceId path: an order id, or for "target" the Intent's target, such as acme/api#42. |
