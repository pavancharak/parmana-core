---
title: "Interface: PolicyInEffect"
---

The policy a capability's requests must declare right now, and what a
request under it must carry. The response of
GET /policies/in-effect?capability=...

## Members
| Name | Kind | Type | Description |
| --- | --- | --- | --- |
| `capability` | Property | `string` |  |
| `policy` | Property | `{ readonly name: string; readonly version: string; readonly schemaVersion: string; }` | Declare this, exactly, as the request's `policy`. |
| `description` | Property | `string \| null` | The policy author's description for people, or null. |
| `authorityGrantRequired?` | Property | `true \| undefined` | Present only when the policy requires it: your key needs a current authority grant for this capability, and each request must be within the grant's limits (RFC-0023 phase 3). |
| `signals` | Property | [`PolicySignalRequirements`](/sdks/reference/typescript/interfaces/PolicySignalRequirements) |  |
