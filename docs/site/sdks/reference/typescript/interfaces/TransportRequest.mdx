Transport request.

## Members

| Name                   | Kind     | Type                                              | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| ---------------------- | -------- | ------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `path`                 | Property | `string`                                          | Relative API path. Example: /execute                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `method`               | Property | `"GET" \| "POST" \| "PUT" \| "PATCH" \| "DELETE"` | HTTP method.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `body?`                | Property | `unknown`                                         | Optional request body.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `headers?`             | Property | `Readonly<Record<string, string>> \| undefined`   | Optional request headers.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `nonThrowingStatuses?` | Property | `readonly number[] \| undefined`                  | HTTP status codes that must be returned as an ordinary TransportResponse instead of being mapped to a thrown ParmanaError subclass, because this specific route's response body at that specific status is not the shared `\{error, code?\}` envelope. Default: none (every status >= 400 throws). Today exactly one route needs this: POST /policies/validate returns `\{valid, errors\}` — not `\{error, code?\}` — at 400 and 404 (but the shared envelope still applies to 401, generated by caller-auth middleware before this route's own handler ever runs). See PolicyApi.validate and /api-reference/error-handling. |
