---
title: "Interface: OfflineVerificationResult"
---

The result of an offline verification.

## Members

| Name                     | Kind     | Type                   | Description                                                                                                                                                                                                                        |
| ------------------------ | -------- | ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `valid`                  | Property | `boolean`              | True only when the hash matches and the signatures verify. For a trust record, the signatures array must verify, and from the cutover on it must carry both hybrid signatures. For an execution intent, its signature must verify. |
| `hybridSignaturesValid?` | Property | `boolean \| undefined` | Whether the trust record's `signatures` array verifies. Set for trust records only.                                                                                                                                                |
| `hashValid`              | Property | `boolean`              | The record's own hash matches a fresh SHA-256 of its canonical form.                                                                                                                                                               |
| `algorithmsChecked`      | Property | `readonly string[]`    |                                                                                                                                                                                                                                    |
| `errors`                 | Property | `readonly string[]`    | Why verification failed, in plain words. Empty when valid.                                                                                                                                                                         |
