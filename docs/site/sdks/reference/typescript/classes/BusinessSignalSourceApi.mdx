## Members
| Name | Kind | Type | Description |
| --- | --- | --- | --- |
| `list` | Method | `() => Promise<BusinessSignalSource[]>` | Every registration, active and revoked. Maps to GET /business-signal-sources. |
| `proposeChange` | Method | `(input: ProposeBusinessSignalSourceChangeInput) => Promise<BusinessSignalSourceChange>` | Proposes registering or revoking a business signal source. Nothing changes until a different person approves it. Maps to POST /business-signal-sources/changes. |
| `listChanges` | Method | `(status?: PendingPolicyChangeStatus \| undefined) => Promise<BusinessSignalSourceChange[]>` | Lists business signal source changes, newest first. Maps to GET /business-signal-sources/changes. |
| `approveChange` | Method | `(changeId: string, stepUpAuthorization: PolicyChangeStepUpAuthorization) => Promise<BusinessSignalSourceChange>` | Approves and applies a business signal source change. Maps to POST /business-signal-sources/changes/\{id\}/approve. The caller must not be the proposer and must have a registered step up key. Make `stepUpAuthorization` with `signPolicyChangeStepUp()`, the change id as `pendingPolicyChangeId`, and action "approve". |
| `rejectChange` | Method | `(changeId: string, rejectionReason: string, stepUpAuthorization: PolicyChangeStepUpAuthorization) => Promise<BusinessSignalSourceChange>` | Rejects a business signal source change. Same caller rules as approveChange(); sign with action "reject". A reason is required. |
