## Members
| Name | Kind | Type | Description |
| --- | --- | --- | --- |
| `list` | Method | `() => Promise<ExternalConnector[]>` | Every registration, active and revoked. Maps to GET /external-connectors. |
| `proposeChange` | Method | `(input: ProposeExternalConnectorChangeInput) => Promise<ExternalConnectorChange>` | Proposes registering or revoking an external connector. Nothing changes until a different person approves it. Maps to POST /external-connectors/changes. |
| `listChanges` | Method | `(status?: PendingPolicyChangeStatus \| undefined) => Promise<ExternalConnectorChange[]>` | Lists external connector changes, newest first. Maps to GET /external-connectors/changes. |
| `approveChange` | Method | `(changeId: string, stepUpAuthorization: PolicyChangeStepUpAuthorization) => Promise<ExternalConnectorChange>` | Approves and applies an external connector change. Maps to POST /external-connectors/changes/\{id\}/approve. The caller must not be the proposer and must have a registered step up key. Make `stepUpAuthorization` with `signPolicyChangeStepUp()`, the change id as `pendingPolicyChangeId`, and action "approve". |
| `rejectChange` | Method | `(changeId: string, rejectionReason: string, stepUpAuthorization: PolicyChangeStepUpAuthorization) => Promise<ExternalConnectorChange>` | Rejects an external connector change. Same caller rules as approveChange(); sign with action "reject". A reason is required. |
