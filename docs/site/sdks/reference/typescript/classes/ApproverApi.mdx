## Members
| Name | Kind | Type | Description |
| --- | --- | --- | --- |
| `list` | Method | `() => Promise<ApprovalIssuer[]>` | Every approver key the server trusts or trusted, revoked ones marked. Maps to GET /approval-issuers. |
| `proposeChange` | Method | `(input: ProposeApproverChangeInput) => Promise<ApprovalIssuerChange>` | Proposes adding or revoking an approver key. Nothing changes until a different person approves it. Maps to POST /approval-issuers/changes. |
| `listChanges` | Method | `(status?: PendingPolicyChangeStatus \| undefined) => Promise<ApprovalIssuerChange[]>` | Lists approver changes, newest first. Maps to GET /approval-issuers/changes. |
| `approveChange` | Method | `(changeId: string, stepUpAuthorization: PolicyChangeStepUpAuthorization) => Promise<ApprovalIssuerChange>` | Approves and applies an approver change. Maps to POST /approval-issuers/changes/\{id\}/approve. The caller must not be the proposer and must have a registered step up key. Make `stepUpAuthorization` with `signPolicyChangeStepUp()`, the change id as `pendingPolicyChangeId`, and action "approve". |
| `rejectChange` | Method | `(changeId: string, rejectionReason: string, stepUpAuthorization: PolicyChangeStepUpAuthorization) => Promise<ApprovalIssuerChange>` | Rejects an approver change. Same caller rules as approveChange(); sign with action "reject". A reason is required. |
