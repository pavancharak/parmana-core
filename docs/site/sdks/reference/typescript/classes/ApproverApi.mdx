### approveChange()

> **approveChange**(`changeId`, `stepUpAuthorization`): `Promise`\<[`ApprovalIssuerChange`](/sdks/reference/typescript/interfaces/ApprovalIssuerChange)\>

Approves and applies an approver change. Maps to POST
/approval-issuers/changes/{id}/approve. The caller must not be the
proposer and must have a registered step up key. Make
`stepUpAuthorization` with `signPolicyChangeStepUp()`, the change id
as `pendingPolicyChangeId`, and action "approve".

#### Parameters

##### changeId

`string`

##### stepUpAuthorization

[`PolicyChangeStepUpAuthorization`](/sdks/reference/typescript/interfaces/PolicyChangeStepUpAuthorization)

#### Returns

`Promise`\<[`ApprovalIssuerChange`](/sdks/reference/typescript/interfaces/ApprovalIssuerChange)\>
