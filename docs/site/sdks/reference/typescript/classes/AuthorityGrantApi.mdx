## Members
| Name | Kind | Type | Description |
| --- | --- | --- | --- |
| `list` | Method | `() => Promise<AuthorityGrant[]>` | Every grant, active and revoked. Maps to GET /authority-grants. |
| `proposeChange` | Method | `(input: ProposeAuthorityGrantChangeInput) => Promise<AuthorityGrantChange>` | Proposes granting or revoking an agent's authority. Nothing changes until a different person approves it. Maps to POST /authority-grants/changes. |
| `listChanges` | Method | `(status?: PendingPolicyChangeStatus \| undefined) => Promise<AuthorityGrantChange[]>` | Lists authority grant changes, newest first. Maps to GET /authority-grants/changes. |
| `approveChange` | Method | `(changeId: string, stepUpAuthorization: PolicyChangeStepUpAuthorization) => Promise<AuthorityGrantChange>` | Approves and applies an authority grant change. Maps to POST /authority-grants/changes/\{id\}/approve. The caller must not be the proposer and must have a registered step up key. Make `stepUpAuthorization` with `signPolicyChangeStepUp()`, the change id as `pendingPolicyChangeId`, and action "approve". |
| `rejectChange` | Method | `(changeId: string, rejectionReason: string, stepUpAuthorization: PolicyChangeStepUpAuthorization) => Promise<AuthorityGrantChange>` | Rejects an authority grant change. Same caller rules as approveChange(); sign with action "reject". A reason is required. |
