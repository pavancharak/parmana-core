title: "Class: ExecutionApi"
---

Execution API.

Responsibilities
----------------
- Runtime health check
- Execute Business Transactions

This API does NOT:
- verify trust records
- replay executions
- generate receipts
- validate policies

## Members
| Name | Kind | Type | Description |
| --- | --- | --- | --- |
| `health` | Method | `() => Promise<unknown>` | Returns the Runtime health status. |
| `version` | Method | `() => Promise<unknown>` | Returns the Runtime name, version, and API version. Requires caller authentication, unlike GET /health. |
| `execute` | Method | `(transaction: BusinessTransaction) => Promise<ExecutionTrustRecord>` | Execute a Business Transaction. |
