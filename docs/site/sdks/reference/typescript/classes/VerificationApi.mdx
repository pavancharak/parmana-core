## Members
| Name | Kind | Type | Description |
| --- | --- | --- | --- |
| `verify` | Method | `(businessTransactionId: string) => Promise<`[`Verification`](/sdks/reference/typescript/interfaces/Verification)`>` | Runs a fresh verification of an Execution Trust Record. Maps to POST /verify. Each call re-verifies the record and appends a new Verification to its history, distinct from getLatest() (GET /verification/:id), which reads the most recent one without re-verifying. |
| `getLatest` | Method | `(businessTransactionId: string) => Promise<`[`Verification`](/sdks/reference/typescript/interfaces/Verification)`>` | Returns the latest Verification for a Business Transaction, without performing a fresh verification. Maps to GET /verification/:id. |
