---
title: "Playground (retired)"
description: "The public Playground and its sandbox were retired on 2026-10-20. Run Parmana on your own machine with the Quickstart."
---

The public Playground and the public sandbox have been retired. Their demo key has been withdrawn, so no request to a public Parmana server will succeed.

To see Parmana work, run it on your own machine with the [Quickstart](/quickstart). To connect your own system, see [Production deployment](/deployment/production).
