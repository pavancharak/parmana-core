This book takes you from nothing to a production integration: an AI agent that can act on a real system only when a
policy and a person allow it, with a signed record of every decision. It is the companion to
[The Parmana Handbook](/handbook/overview), which explains how each part of Parmana is built. This book explains how to
**build with** it.

Download it as one PDF: [build-with-parmana.pdf](/build-with-parmana.pdf).

## How the book is written

- **Every statement is checked against the code.** Where the book and the code disagree, the code wins and the book
  is fixed. Anything not verified in production says so.
- **The reference chapters are generated from the code.** [Every endpoint](/build-book/reference-endpoints),
  [every SDK method](/build-book/reference-sdk) and [every error code](/build-book/reference-errors) are produced by
  `scripts/generate-build-book-reference.ts` from the OpenAPI file, the SDK source and the server's error classes. A
  test fails when they fall behind the code.
- **Examples are real.** Responses are captured from the running server; tutorial output is what the tutorial prints.
- **Procedures state what to expect.** Where a step can fail, it says what you see and what to do.

## Versions

This edition describes the code on `main` as of 2026-10-01. The published SDKs are 1.6.0 (`@parmana/sdk` on npm,
`parmana` on PyPI), published 2026-10-11. Methods marked **1.5.0** need that version or later:
`policyInEffect` and `policy_in_effect`, `verifyParmanaRelease` and `verify_parmana_release`.
