<Info>
  **Report security issues privately.** Do not open a public issue for a
  vulnerability. Follow
  [SECURITY.md](https://github.com/pavancharak/parmana-core/blob/main/SECURITY.md).
</Info>

## Questions, bugs and ideas

- **Questions and ideas:** [GitHub Discussions](https://github.com/pavancharak/parmana-core/discussions).
- **Bugs:** [GitHub Issues](https://github.com/pavancharak/parmana-core/issues). Include the version, the
  steps to reproduce, and what you expected.
- **Everyone taking part** follows the
  [Code of Conduct](https://github.com/pavancharak/parmana-core/blob/main/CODE_OF_CONDUCT.md).

## Contributing code

Parmana is licensed under the [Apache License 2.0](/license). Pull requests from outside Parmana Systems
are welcome. For anything larger than a small fix, open an issue or a discussion first. Every commit
must carry a `Signed-off-by` line, certifying the [Developer Certificate of Origin](https://developercertificate.org):
add it with `git commit -s`. Read [CONTRIBUTING.md](https://github.com/pavancharak/parmana-core/blob/main/CONTRIBUTING.md) before you open one.

## Security

Report vulnerabilities through the private advisory channel in
[SECURITY.md](https://github.com/pavancharak/parmana-core/blob/main/SECURITY.md). The security
challenge, which asks you to try to break a copy of Parmana you run yourself, is in
[SECURITY-CHALLENGE.md](https://github.com/pavancharak/parmana-core/blob/main/SECURITY-CHALLENGE.md).
