These essays explain all of Parmana, one idea at a time, in plain language. Each starts from a concrete situation,
explains the idea, shows how Parmana implements it, and says what it does **not** do. Every claim is backed by the
[claims register](https://github.com/pavancharak/parmana/blob/main/docs/CLAIMS.md); where a feature is built but not
yet in use, or tested but not seen live, the essay says so.

Read them in order for the whole system, or start with [How Parmana works, end to end](/essays/04-how-parmana-works),
the map the others fill in. The reference for each topic is in [Concepts](/concepts/policies-and-the-decision) and
[Guides](/guides/authorize-and-execute).
