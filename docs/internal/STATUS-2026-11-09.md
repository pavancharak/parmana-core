# Project status: 2026-11-09

This document lists what is pending, why each item matters, how to resolve it, who resolves it, and when. It also lists the
switches that enable or disable features, and the current progress and next steps. It records the state as of 2026-11-09,
after the work in PRs #535 to #544. Where GitHub shows a different state, GitHub is correct; update this document.

## 1. Current stage

Core work is in place. Trust records, the inbound check, approvals, the approval record (G-143), the test database
configuration, and the crypto configurations (Ed25519 by default, hybrid, and ML-DSA-65 alone) all exist in code, with tests.

What remains is mostly decisions and sign-off, not code:

- Commits from this work are not GPG-signed, and `main` requires signed commits. The repository has merged several commits
  without signatures.
- Some changes are waiting on a second reviewer.
- Some decisions are the owner's: whether external consumers of inbound records are needed, which configuration is the default
  for crypto, and the business's own route for the no-bypass probe.

## 4. How to enable and disable each switch

| Switch                           | How to enable                                                                                                                                                       | How to disable                                             | Notes                                                                                                      |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| Signed commits on `main`         | Settings → Branches → `main` → "Require signed commits" on, admin bypass off                                                                                        | Turn "Require signed commits" off                          | Turning it off lets unsigned merges through. Turn it back on straight after.                               |
| Required review on `main`        | Settings → Branches → `main` → require one approving review                                                                                                         | Turn the requirement off for one merge only                | Restore it immediately after.                                                                              |
| Commit-signature check, required | Add "Commit signatures" as a required status check on `main`                                                                                                        | Remove the required check                                  | Advisory until added.                                                                                      |
| Hybrid crypto mode               | Set `CRYPTO_MODE=hybrid`, `SECONDARY_SIGNATURE_PROVIDER=dilithium3`, `KEY_PROVIDER=local`, and both key pairs (`default`, `default-secondary`) in `PARMANA_KEY_DIR` | Set `CRYPTO_MODE=single` (the default)                     | The server refuses to start in hybrid mode if a key pair is missing, or under KMS.                         |
| ML-DSA-65 alone                  | Set `CRYPTO_MODE=single` and `PRIMARY_SIGNATURE_PROVIDER=ml-dsa-65`, with `KEY_PROVIDER=local`                                                                      | Set `PRIMARY_SIGNATURE_PROVIDER=ed25519` (the default)     | Refused at startup under `KEY_PROVIDER=aws-kms`. | The `pq` value                   | Not available.
