Developer reference#

Portal home · Glossary · FAQ

This section is the lookup material: where each definition lives, the complete indexes, the configuration, and the error codes. Use it when you know the name of a thing and want its exact definition.

Core concepts, quickly#

Concept Short definition Full entry
Business Transaction The declared request: authority, authorization, intent, policy, signals. Glossary
Execution Trust Record The signed evidence for one transaction. Glossary
Policy version in effect The most recently approved version of a policy name. Glossary
Human approval A signed artifact from a trusted approver, verified by the server. Glossary
Maker-checker Two-person approval of a policy change, with a step-up signature. Glossary

Configuration#

Parmana is configured with environment variables. The full reference is in Environment variables. The variables a deployment must set are in Deployment.

Configuration errors stop the server at start-up, with a message that names the variable. The messages the verification observed are listed in Troubleshooting.
