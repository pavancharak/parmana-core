Get started/Parmana developer portal

Parmana developer portal#

Parmana makes sure that AI agents and business applications take only the actions the organization has approved, and keeps signed, independently verifiable evidence of each action.

This portal documents the SDKs, the REST API, the policy and governance model, deployment, security and evidence verification, and troubleshooting. Every behaviour described here was checked against the source code in this repository, and the examples were run. Where something was not run, the page says so.

Start here: Getting started, then Concepts and the tutorials.

How to read this portal#

Each feature carries one of these labels:

Label Meaning
Implemented In the code, and exercised by a test, example or live run recorded in COVERAGE.md.
Experimental In the code and reachable, but opt-in, or not yet covered by a production runbook. Experimental operations are marked x-stability: experimental in the OpenAPI document.
Test only Works only with NODE_ENV=test or a test fixture. Never use it in a deployment.
Planned Named in the design documents, not in the code. Not documented as usable.

Runnable examples#

The examples in examples/ are the code the tutorials point to. They run against a local server that you start from this repository.

Verification tools#

  • tools/generate-indexes.mjs regenerates the method and endpoint indexes from the SDK source and the OpenAPI document.
  • tools/check-docs.mjs checks that the portal's links resolve and that every public SDK method and OpenAPI operation is mentioned somewhere in the portal.

Relationship to the existing documentation#

The repository already has a larger, Mintlify-based site in docs/site/, technical guides in docs/guides/, and generated reference pages. This portal does not replace them. Where a topic is already covered there, this portal links to it instead of repeating it. Two existing pages were found to be out of date for a fresh local start; see COVERAGE.md.
