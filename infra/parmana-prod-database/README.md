# Parmana production database (step 2 of the production build)

RDS PostgreSQL 16, single-AZ, db.t4g.micro, 20 GB gp3 with autoscaling to 100 GB, encrypted.
Private subnets only, reached through the database security group. No public access.

Deletion protection is on, and a final snapshot is required on delete (`parmana-prod-final`).
The master password is generated by RDS and stored in Secrets Manager. Terraform does not hold it.

## Before plan or apply

1. Confirm the account: `aws sts get-caller-identity --profile parmana-prod` must show `<ACCOUNT_ID>`.
2. `terraform init`, then `terraform plan "-var-file=prod.tfvars" "-out=prod.tfplan"`.
3. Review the plan. Apply only the saved plan: `terraform apply prod.tfplan`.

## Before you delete anything

Deletion protection must be turned off first (a deliberate change), and a final snapshot is taken automatically.
Do not run destroy without the owner's written approval.

## State

State is local until the remote backend is added. Back up `terraform.tfstate` outside the repo. Never commit it.
