Access is not authority. Parmana sits after the others.

Most institutions already run IAM, an API gateway and some kind of guardrail. Each answers a different question. Parmana answers the one none of them do.

What each tool answers

IAM, scopes, rolesWho may access a system. Scopes are coarse and long-lived.
API gatewayWhether a request may pass, and how fast.
LLM guardrailsWhether text looks harmful, off topic or injected. They filter text, not actions.
Policy engines (for example OPA, Cedar)Whether a rule allows a decision. Often a building block, and they need you to write the rules and feed them facts.
Agent framework confirmationsWhether a person clicked yes in the agent's own process. The agent may be able to skip it.
ParmanaWhether this specific action, with its parameters and amount, falls within the authority you delegated, whether a named person approved it, and a signed record of what ran or was refused.

What Parmana adds

A person per action, not per role

An approval covers one action, on one resource, up to one amount, once, until it expires.

The agent never holds the credentials

The gateway holds them and releases each action only after checking the signed authorization.

Evidence, not logs

Each action and refusal has a signed record that a third party can verify without access to your systems.

Governed rules

Policies, approvers and connectors change only through a second person, and each change is signed.

Where Parmana is weaker

  • It does not read text. Use a guardrail for prompt injection, toxic output and data leakage.
  • It only covers actions that go through it. An agent with other credentials, or a system reached another way, is outside it.
  • A person in the loop is slow by design. Actions that need approval carry human latency.
  • It does not yet check declared facts against your systems unless a policy names a signal source for them. A policy engine fed from your own data can use facts Parmana does not see.
  • It ships no ready-made connectors. You register an endpoint or write a connector.
  • It is young. No metrics, tracing or dashboards yet. IAM products and API gateways have years of production use behind them.

Full list of limitations

Use them together. Parmana does not replace IAM, AI security or AI governance. It sits in front of the actions an agent takes, after those controls have run.
