The problem

Access is not authority.

Access controls answer one question: can this agent reach this system? That matters, but it does not answer the question that matters when an agent is about to issue a refund or change a record: was this specific action, for this amount and in these circumstances, actually delegated to it?

Keep control when AI acts for your business. Parmana answers that question before the action runs, using rules your business writes.

What Parmana does

Three capabilities, one record.

Parmana does not record what an AI agent says it did. It checks each action against your authority, and binds that decision to evidence of what actually executed.

1

Independent verification

Check whether an action was authorized against your policies, without relying on the agent's own claims.

2

Execution evidence

Establish what was requested, what was authorized and what actually ran, including refusals.

3

Tamper-evident record

Signed evidence that anyone can check offline, with only the public key they choose to trust.

How it works

Four stages before an action runs.

Each stage is built and tested. Read the detail.

DeclaredYour authority is written as explicit, versioned rules: what each action may do, up to what amount, and when a person must approve.
AuthorizedEach proposed action is checked against those rules. If no rule matches, the action is refused.
ExecutedOnly permitted actions pass the enforcement boundary. On supported paths the agent never holds the connector credentials.
ProvenA signed record of the decision and the release, verifiable offline by anyone you choose to trust.

An example

A refund that needed a manager.

A support agent asks to refund 4,000 to a customer. Your policy lets the agent refund up to 500 on its own. Above 500, it needs a signed approval from a named manager for that order and that amount.

Parmana refuses the request, so nothing is refunded. The manager signs an approval for that order and amount, valid for 15 minutes and usable once. The agent sends the request again. Parmana releases the refund, and the record shows the decision, the approval and the release.

Be clear about the limits

Parmana is a prototype.

It enforces authority for actions that pass through it. It does not read the text a model produces, and it does not replace access control, AI security or governance. Read the status and limitations before you evaluate it.
