# PoAE benchmark

This folder holds the specification for the PoAE benchmark. The specification is in [benchmark-spec.md](benchmark-spec.md).

- The benchmark has 20 tests in five categories. 14 can be run now and 6 are blocked by named gaps.
- No test has been run. Results are recorded with the templates in [`testing/templates/`](../templates/).
- The benchmark does not change Parmana's cryptographic core. It uses the existing interfaces.
