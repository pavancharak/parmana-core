# @parmana/connector-paytm

Paytm refund connector for Parmana, the authorization layer for AI execution: forwards a Parmana-authorized paytm:refund capability to the trusted, out-of-process Paytm connector service (parmana-paytm-agent) over HTTPS. Never calls Paytm's own API directly.

This package is part of [Parmana](https://docs.parmanasystems.com), the authorization layer for AI execution. Read the [Parmana documentation](https://docs.parmanasystems.com) for how it fits with the rest of the system.

## Install

```bash
npm install @parmana/connector-paytm
```

Requires Node.js 24 or later.
