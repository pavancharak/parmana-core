# @parmana/connector-slack

Slack connector for Parmana: posts a message via Slack's real chat.postMessage Web API after a Parmana-authorized slack:post-message capability. In-process, real HTTP calls (like HubSpot/GitHub), not a proxy to a separate service.

This package is part of [Parmana](https://docs.parmanasystems.com), the authorization layer for AI execution. Read the [Parmana documentation](https://docs.parmanasystems.com) for how it fits with the rest of the system.

## Install

```bash
npm install @parmana/connector-slack
```

Requires Node.js 24 or later.
